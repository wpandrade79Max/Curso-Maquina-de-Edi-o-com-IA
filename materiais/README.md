# Materiais

- `imagens/`: logos, fotos e artes pequenas que podem ser versionadas.
- `audio/`: arquivos de áudio usados durante a edição.
- `videos/`: vídeos brutos usados durante a edição.

Áudios e vídeos grandes devem permanecer no Google Drive. Quando necessários,
anexe-os ao chat ou peça para copiá-los ao ambiente de trabalho.
