# Curso Máquina de Edição com IA

Este repositório guarda os exercícios, projetos e configurações usados no curso.
Ele foi organizado para trabalhar pelo Codex Cloud e manter o conteúdo acessível
a partir do Mac ou do Windows.

## Estrutura

- `.agents/`: skills usadas pelo Codex, incluindo as práticas do Remotion.
- `aulas/`: anotações e exercícios separados por aula.
- `projetos/`: projetos Remotion criados durante o curso.
- `materiais/`: imagens, áudios e vídeos usados nos projetos.

## Como trabalhar

1. Abra um chat em nuvem com o ambiente deste curso.
2. Informe em qual aula ou projeto deseja trabalhar.
3. Anexe ao chat somente os materiais necessários para a tarefa atual.
4. Peça ao Codex para colocar cada arquivo na pasta correta.
5. Ao concluir uma etapa, revise as alterações antes de fazer commit e push.

Arquivos grandes de vídeo, áudio, renders, dependências e caches não são
versionados. Eles podem ficar no Google Drive e ser copiados para o ambiente
quando forem necessários.
